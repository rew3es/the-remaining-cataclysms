# Технический манифест проекта (2.5D the-remaining-cataclysms на Godot 4)

Этот документ - наш единый источник правил. Чтобы мы не ломали друг другу сцены и не тратили время на поиск багов, придерживаемся этих стандартов при создании графики, монстров и уровней.

---

## 1. Структура папок и работа с Git

Каждый разработчик работает строго в своей изолированной папке, чтобы избежать конфликтов при слиянии (Merge Conflicts).

```text
res://
├── README.md               # Этот файл (редактируем по договоренности)
├── project.godot           # Настройки проекта (редактируем по договоренности)
├── common/                 # Общие базовые скрипты (Hitbox.gd, Hurtbox.gd)
├── player/                 # Всё, что касается главного героя
├── enemies/                # Папка для монстров
│   ├── _base/              # Базовая сцена BaseEnemy.tscn (не трогать без обсуждения)
│   ├── slime/              # Монстр №1 (Делает Разработчик А)
│   └── skeleton/           # Монстр №2 (Делает Разработчик Б)
└── levels/                 # Локации и комнаты
	├── tilesets/           # Общие тайлсеты земли и стен
	└── forest_01/          # Конкретная комната
```

**Правила Git:**
1. Перед началом работы всегда делаем `git pull`.
2. Не редактируем одновременно один и тот же `.tscn` файл.
3. Если нужно поменять `project.godot` (например, добавить кнопку управления), предупреждаем напарника.

## 2. Правила графики (GIMP)

* **Формат файлов:** Только `.png` с прозрачным фоном (альфа-каналом).
* **Именование файлов:** Только латиница в нижнем регистре через нижнее подчеркивание:
  * `slime_walk_01.png`, `slime_walk_02.png`
  * `tree_oak.png`, `grass_tile.png`

---

## 3. Физические слои (Collision Layers)

Мы используем единую таблицу слоев (`Project Settings → Layer Names → 2D Physics`). Не ставим галочки наугад!

| № Слоя | Название | За что отвечает |
| --- | --- | --- |
| **1** | `World` | Стены, вода, деревья, обрывы (твердые препятствия) |
| **2** | `Player` | Физический коллайдер (ступни) игрока |
| **3** | `Enemies` | Физические коллайдеры (ступни) всех врагов |
| **4** | `PlayerHurtbox` | Зона тела игрока, которая получает урон |
| **5** | `EnemyHurtbox` | Зона тела врагов, которая получает урон |
| **6** | `Hitboxes` | Оружие, снаряды и зоны атаки |
